One sentence, 227 characters, that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun. It is the whole entry: no code, no explanation — just the pitch.

## The pitch

> Describe the app idea you have carried for years in plain words on make.fun, and an AI agent will build the first version for you — free to enter, no code to write, and you can watch it take shape before you commit to anything.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line to `/output/entry.txt`, where the bounty harness reads it.
